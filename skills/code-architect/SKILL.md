## Software Architecture Directives
- **Modularity**: Split logic into single-responsibility modules, controllers, and services.
- **Strict Typing**: Use explicit type annotations for all function parameters, return types, and class attributes.
- **Robust Error Trapping**: Handle boundary exceptions cleanly, avoiding bare `except:` or unhandled null references.
- **Zero Emojis**: Never insert emojis into docstrings, variable names, logs, terminal outputs, or user responses.
- **Verification Ready**: Always include runnable verification blocks (`if __name__ == "__main__":`) or test fixtures.
