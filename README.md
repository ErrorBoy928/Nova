## 🚀 Quick Start Guide

### 1. Master Desktop Studio
```bash
pip install -r requirements.txt
python main.py
```
Or simply double-click **`Nova_AI.bat`** on your Desktop.

### 2. Multi-Process Cloud & Bot Runner (WhatsApp + Discord)
```bash
npm install
node master.js
```
Runs both the WhatsApp Baileys engine and Discord Superbot simultaneously with automatic crash recovery.

## 🛠️ Remote Commands

| Command | Channel | Description |
| :--- | :--- | :--- |
| `!screen` | WhatsApp & Discord | Captures PC desktop screenshot and embeds high-res image |
| `!pc <cmd>` | WhatsApp & Discord | Executes app or system action (e.g. `!pc open chrome`) |
| `!pctasks` | WhatsApp & Discord | Checks autonomous active agent tasks |
| `!pcstats` | WhatsApp & Discord | Reports live CPU, RAM, and Disk space |
| `!stop` / `!start` | WhatsApp | Pauses / resumes AI auto-responder for the current chat |
| `!secret <key>` | Discord | Stores / retrieves credentials in encrypted secret vault |
